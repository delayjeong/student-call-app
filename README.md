# 학생 호출·전달 시스템
https://script.google.com/macros/s/AKfycbzsNNUH87PdGbbyc03DIUPJIpGxXseFBM6UvkYopkBaI7vuL2pCTMkzItVrE67ohfhWig/exec

선생님이 휴대폰·PC의 Apps Script 웹앱에서 학생 호출 또는 전달사항을 보내면, 해당 반 전자칠판(Android)에 팝업과 TTS가 표시됩니다.

- 학생 호출: 특정 반의 특정 학생을 지정해 호출
- 전달사항: 특정 반 또는 학년 전체에 전달
- 전달사항 TTS: `정연기 선생님 전달사항입니다. (전달 내용)` 형식
- 학교 PC 서버 없이 Google 스프레드시트 + Apps Script로 동작

```
선생님 휴대폰·PC ── Apps Script 교사용 웹 ──▶ Google 스프레드시트
                                              ▲
전자칠판 APK ───── 10초마다 호출·전달 확인 ──┘
```

| 폴더 | 내용 |
|---|---|
| `apps-script/` | Apps Script 서버 및 교사용 웹 (`Code.gs`, `Teacher.html`) |
| `android/` | 전자칠판 수신 앱 |
| `legacy/python-server/` | 이전 Python 서버 방식 참고용 |

설치 방법은 `SETUP.md`를 참고하세요.

## 실제 학급 구성
- 1학년: 1~5반
- 2학년: 1~5반
- 3학년: 1~4반

Apps Script 기본 설정의 `CLASS_COUNTS` 값은 `5,5,4`입니다.

## 교사용 웹 기능
- 학생 호출 / 전달사항 모드 분리
- 학년·반 선택
- 전달사항은 `선택한 반` 또는 `학년 전체` 선택 가능
- 학년 전체 전달은 보내기 전 확인창 표시
- 선택 대상에서 최근 확인한 전자칠판 대수 표시
- 최근 호출·전달 기록, 표시 확인, 취소, 다시 표시
- 운영 시간 밖에는 전송 불가
- 교사용 키는 한 번 입력해 저장한 뒤 실제 값을 화면에 다시 표시하지 않음

## 전자칠판 앱 기능
- 등록된 반의 학생 호출 수신
- 같은 학년의 `학년 전체 전달사항` 수신
- 다른 앱 위 중앙 팝업, 알림음, 확인 버튼, 자동 닫힘
- 오버레이 권한이 없으면 중요 알림 / 전체 화면 알림으로 대체
- 학생 호출 TTS: `김민수 학생, 교무실로 오세요. 김수학 선생님 호출입니다.`
- 전달사항 TTS: `김수학 선생님 전달사항입니다. (내용)`
- 학생 호출 화면 테스트 / 전달사항 화면·TTS 테스트 제공
- 앱 부팅 시 자동 수신 옵션
- 웹앱 주소와 수신기 키는 한 번 저장하면 앱 화면에 다시 표시하지 않음
- 연결 정보를 변경할 때는 새 값을 입력해 덮어씀

## 수신기 UI
버튼은 기능을 직접 알 수 있도록 다음처럼 표시합니다.
- `반·수신 설정 저장`
- `웹앱 주소·수신기 키 저장`
- `연결 정보 다시 입력`
- `팝업 표시 권한 설정`
- `앱이 꺼지지 않도록 설정`
- `호출·전달 수신 시작`
- `호출·전달 수신 중지`
- `학생 호출 화면 테스트`
- `전달사항 화면·TTS 테스트`

## Apps Script 설정
Apps Script 편집기 → 프로젝트 설정 → 스크립트 속성에서 설정합니다.

| 속성 | 기본값 | 설명 |
|---|---|---|
| `ACTIVE_HOURS` | `08:00-22:00` | 운영 시간 |
| `POLL_SECONDS` | `10` | 전자칠판 확인 간격(3~60초) |
| `CLASS_COUNTS` | `5,5,4` | 학년별 반 수 |
| `LOCATIONS` | `교무실,행정실,상담실,보건실,과학실` | 호출 위치 빠른 선택 |
| `KEEP_DAYS` | `7` | 기록 보관 일수 |
| `TEACHER_KEY` | 자동 생성 | 교사용 웹 인증 키 |
| `DEVICE_KEY` | 자동 생성 | 전자칠판 수신기 인증 키 |

기존 설치를 업데이트할 때 `setup()`은 기존 `TEACHER_KEY`, `DEVICE_KEY`가 있으면 그대로 유지합니다.

## 스프레드시트
`호출기록` 시트는 기존 8열 기록을 유지하면서 다음 열이 추가됩니다.
- `유형`: `call` / `notice`
- `전달사항`: 전달사항 본문

기존 호출 기록은 자동으로 `call`로 취급합니다.

## 보안
- `TEACHER_KEY`와 `DEVICE_KEY`를 GitHub, 문서, 게시판 등에 올리지 마세요.
- 교사용 웹과 수신기 앱은 저장된 키를 화면에 다시 표시하지 않습니다.
- 공개 저장소나 외부에 키가 노출되었다면 해당 키는 더 이상 비밀로 간주하지 말고 새 키로 교체하세요.
- 스프레드시트에는 학생 이름이 저장되므로 공유 범위를 관리자 중심으로 제한하세요.

## APK 받기
`main`의 Android 코드가 바뀌면 GitHub Actions가 서명된 release APK를 빌드하고 Releases에 게시합니다.

## 전자칠판 확인 API
`GET <웹앱 주소>?action=poll&classId=2-3&deviceId=<기기ID>&key=<수신기 키>&after=<마지막 번호>&acked=<표시한 번호들>`

전자칠판 `2-3`은 다음 두 대상을 함께 확인합니다.
- `2-3`: 해당 반 호출/전달
- `2-*`: 2학년 전체 전달

응답의 `calls` 항목에는 `type`, `teacher`, `student`, `location`, `message`가 포함됩니다.
